# 📚 Data Engineer Interview Preparation

## 🎯 Цель

Системно готовиться к собеседованиям Data Engineer, не пытаясь выучить всё сразу.

Основные направления:

- 🐍 Python
- 🗄️ SQL
- 🌬️ Airflow
- ⚡ Spark
- 🐘 Impala / Hadoop
- 🏗️ Data Engineering

---

# ✅ Daily Checklist

**Цель: 60–90 минут**

### 📖 Теория — 30 минут

- [ ] Выбрать 2 темы
- [ ] Разобрать 2–3 вопроса по каждой теме
- [ ] Сначала ответить самостоятельно
- [ ] Проверить правильный ответ
- [ ] Записать то, что не знал
- [ ] Повторить 2–3 старых вопроса

### 💻 Практика — 30 минут

- [ ] Решить 1 задачу SQL
- [ ] Решить 1 задачу Python

> Если мало времени — решить хотя бы одну задачу.

### 🔄 Повторение — 10 минут

- [ ] Повторить вопросы с ❌ / 🟡
- [ ] Попробовать ответить без подсказки
- [ ] Отметить вопросы, которые всё ещё не понимаю

---

# 🔎 Impala Practice

**1 раз в неделю на работе**

- [ ] Выбрать реальный рабочий запрос
- [ ] Запустить `EXPLAIN`
- [ ] Посмотреть план выполнения
- [ ] Найти `SCAN`
- [ ] Найти `JOIN`
- [ ] Найти `EXCHANGE`
- [ ] Посмотреть partition pruning
- [ ] Запустить запрос
- [ ] Открыть Cloudera Query Profile
- [ ] Посмотреть время выполнения
- [ ] Посмотреть объём обработанных данных
- [ ] Проверить memory / spill
- [ ] Найти самое дорогое место
- [ ] Попробовать понять причину
- [ ] При возможности попробовать оптимизацию
- [ ] Сравнить результат до / после

# 🧠 Правила

1. **Не пытаться выучить всё сразу.**
2. Каждый день — только несколько вопросов.
3. Сначала всегда пытаться ответить самостоятельно.
4. Если не знаешь — разобрать ответ и вернуться позже.
5. Не сидеть над одной задачей больше 30 минут.
6. Не начинать новый курс, пока текущий план не выполняется стабильно.
7. Новые интересные темы складывать в `TODO`, а не бросаться их изучать.
8. Главная цель — **регулярность, а не количество часов**.
