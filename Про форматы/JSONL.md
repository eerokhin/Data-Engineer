## JSONL (JSON Lines)

**JSONL (JSON Lines)** — это текстовый формат хранения данных, где каждая строка является отдельным JSON-объектом.

Главная идея: вместо одного большого JSON-массива мы храним много независимых JSON-записей по одной на строку.

**Обычный JSON**

Например, массив пользователей:

```python
[
  {
    "id": 1,
    "name": "Ivan",
    "age": 30
  },
  {
    "id": 2,
    "name": "Petr",
    "age": 25
  }
]
```
Чтение:

```python
import json

with open("resumes.json") as f:
    data = json.load(f)
```

Проблемы:

- файл должен быть валидным целиком;
- чтобы добавить новую запись, нужно переписывать структуру;
- сложно обрабатывать огромные файлы.

**JSONL**

```python
{"id":1,"name":"Ivan","age":30}
{"id":2,"name":"Petr","age":25}
```

Каждая строка — отдельный JSON.

То есть:

- строка 1 → один объект
- строка 2 → один объект
- строка 3 → один объект
- ...

JSONL удобно обрабатывать потоково.

Например, файл:

```python
resumes.jsonl

{"resume_id":"abc123","name":"Ivan","age":30}
{"resume_id":"def456","name":"Petr","age":25}
{"resume_id":"xyz999","name":"Anna","age":29}
```

Можно читать по одной строке:

```python
import json

with open("resumes.jsonl", "r", encoding="utf-8") as f:
    for line in f:
        resume = json.loads(line)

        print(resume["resume_id"])
```

В памяти находится одна запись, а не весь файл.

Например, если есть файл с 800 000 резюме HH

Чтобы прочитать json, Python загрузит весь файл в RAM.
Если файл 20-50 ГБ, то будет проблема.

JSONL можно читать построчно. Файл хоть 200 ГБ — можно обрабатывать потоково.
Так же и запись в JSONL, данные можно добавлять потоково в новую строку, весь файл перезаписывать не надо.

```python
# Дозапись (append)
with open("resumes.jsonl", "a", encoding="utf-8") as f:
    new_resume = {"resume_id": "new123", "name": "Oleg", "age": 35}
    f.write(json.dumps(new_resume) + "\n")
```

В обычном JSON пришлось бы прочитать весь массив, добавить элемент в список и записать всё заново. 
В JSONL просто дописываете строчку в конец файла — это атомарно и быстро.
